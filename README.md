# cafe-landing

가상의 카페 "모닝브루"를 소개하는 간단한 랜딩 페이지입니다. 별도의 빌드 도구나 프레임워크 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (메인 화면, 대표 메뉴, 소개, 오시는 길) |
| `style.css` | 디자인과 반응형(모바일) 스타일 |
| `README.md` | 이 폴더에 대한 설명 |

## 실행 방법

`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
git clone https://github.com/KMJ0304/cafe-landing.git
cd cafe-landing
start index.html   # Windows
```

## 참고

- 메뉴, 가격, 주소, 전화번호는 모두 예시 데이터입니다.
